# 电商前台利润正式模板包

版本：v1.1
发布日期：2026-08-05

本模板包不含真实店铺、运营、SKU、订单、账户或经营金额。请保留一份空白母版，每次在副本中粘贴业务数据。

## 普通使用：只用 01

打开 `01-电商前台利润单表上传模板.xlsx`：

1. 删除第 2 行的黄色“示例行”，或用真实数据完整覆盖该行。
2. 从第 2 行开始粘贴数据，不要改动第 1 行的 28 个字段名。
3. 日期使用真实 Excel 日期，显示格式为 `yyyy-mm-dd`。
4. 单量、补单单量使用整数；所有金额使用数值，精度保留到分。
5. `SKU/ID`、`record_id`、来源批次等标识符按文本保存，避免科学计数法和前导零丢失。
6. 保存副本后上传数据中台；不要把 `02` 的说明、字典或 Checks 工作表当作经营事实上传。

黄色示例行只用于帮助系统识别日期、整数和金额字段类型，日期固定在 2099-12-31，且明确标记为示例。它不是业务数据，不应进入正式分析。

## 首次在空白数据中台创建模块

在“数据 → Excel 上传”中上传 `01-电商前台利润单表上传模板.xlsx`，勾选该文件后点击“新建模块”，填写：

- 模块名称：`电商前台利润`
- 业务分类：`店铺经营`
- 文件名共同关键词：`前台利润单表上传模板`

字段对应：

| 系统业务字段 | 模板字段 | 类型 |
|---|---|---|
| 日期 | 日期 | 日期 |
| 金额 | GMV | 数值 |
| 数量 | 单量 | 整数 |
| 店铺 | 店铺 | 文字 |
| 其他分析维度 | 运营 | 文字 |

其余字段全部勾选“保留其他字段”。`真实营业额`、`前台利润`、`付费占比`等金额或比例字段应保持为数值，文本字段保持为文字。确认后执行，系统会生成前台利润模块和默认图表。

后续上传正式文件时，只要文件名仍包含上述共同关键词，即可自动归入同一模块。

## 需要从明细、费用和映射重新计算时：使用 02

`02-电商前台利润数据准备与映射模板.xlsx` 面向管理员或数据中台维护者，包含：

- 前台利润标准表
- 经营明细接口
- 费用事实接口
- SKU→店铺/运营/组映射
- 店铺/账户映射
- 字段字典
- 规则与验收
- Checks

统一口径：

```text
真实营业额 = GMV - 补单金额

前台利润 = 出货货值
           - 产品成本
           - 运费
           - 补单金额
           - 平台扣点/毛保
           - 税点
           - 财务成本
           - 佣金
           - 推广费
           + 补单产品成本

付费占比 = 推广费 / GMV（GMV 为 0 时返回 0）
```

聚合键为：`日期 + 平台 + 业务模式 + 店铺 + 运营`。推广费有记录但无经营出库时仍要保留，并允许形成负利润；一店多运营不能自动均摊。

## 发布与校验

- `template-manifest.json` 记录字段顺序、口径、数据边界和文件 SHA-256。
- `SHA256SUMS.txt` 可用于传输后复核文件完整性。
- 正式分享只包含本目录中的两个模板、说明、manifest 和哈希清单；不要附带历史验收表或真实总表。
