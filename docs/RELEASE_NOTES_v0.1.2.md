# v0.1.2：依赖修复与完整下载导航

本版重建 API/Web 运行镜像及离线包，不覆盖 v0.1.1，不改变已有用户的业务数据库。正式 Release 仅在流水线的隔离验收通过后发布。

## 使用者下载哪一个

- 安装平台：Release Assets 中的 `ec-data-platform-20261008.zip`。完整解压，先读包内 `README.md` 和 `docs/GETTING_STARTED.md`，再按 `docs/USER_GUIDE.md` 配置 Docker、密码并启动。
- `ecommerce-workbench-v1.zip` 是可选配置与合成样例，`ec-cloud-kit.zip` 是管理员服务器准备工具；都不是平台安装包。
- `Source code (zip)` 是开发源码，不是离线安装包。复杂 DIY 使用 v0.1.2 标签源码及 `AI_DIY_GUIDE.md`、`AI_PROMPTS.md`。
- 已有实例先备份并按手册升级；不要从新目录随意启动第二套空数据库。本次发布不自动升级本地实例。

## 本版变化

- 更新 Axios、Hono 和两条构建依赖，消除此前 16 条告警中的 15 条。
- braces 没有上游修复版本，采用限制嵌套深度的本地补丁。每次全量审计必须通过实际依赖路径回归，仅处理这一个已授权构建链告警；原始扫描仍为 1 条 high，生产依赖为 0 条。不是“零告警”或完整安全审计。
- 修正 Codespaces 开发容器的运行时数据库密码配置，保持数据库角色隔离和秘密校验。
- ZIP 增加下载/首启导航和依赖安全说明；人类手册、开发 AI 指南、可复制提示词继续独立提供，并检查相对链接。

## 验收与边界

发布流水线检查依赖、类型、单元测试、恶意表头/宽表/历史用户删除等隔离数据库回归，构建 Linux amd64 镜像；对最终 ZIP 解压、镜像来源和发布源码一致性、空数据库首次启动、登录及业务模板处理执行验收。发布后仍需核对实际公开附件。

运行包不包含本机业务库、真实业务上传文件、密码或 API Key；业务模板和样例为合成数据。依赖升级不是完整应用安全审计。ARM 设备和接收方公网服务器未在本次验收范围内，云部署仍需目标机 HTTPS、备份与恢复验收。

完整依赖处理证据见 [依赖安全说明](DEPENDENCY_SECURITY_2026-10-08.md)。
