# 加模块：给使用者看的简版

普通用户可以自己完成，不需要管理员、AI 或开发人员改配置。

## 四步

1. 到「数据」页上传 Excel/CSV。
2. 勾选同一业务、表头兼容的未匹配文件，点击「创建模块」；也可在「模块管理」点击「新建模块」。
3. 逐项选择日期、金额、数量、商品、状态、店铺等字段；如有状态列，选择哪些状态计入有效数据。
4. 点击「保存并处理」。系统会保存模块、自动归入文件、执行 ETL，并生成可用的基础看板。

处理完成后：

- 在模块工作台查看总行数、有效数据、未计入数据和具体原因；
- 在「看板」点击模块标签，查看趋势、排行和占比图；
- 新文件出现新增列或改名列时，按页面提示选择新增、别名或忽略。

详细说明见 [SELF_SERVICE_MODULES.md](./SELF_SERVICE_MODULES.md)。

只有复杂 JOIN、计算字段或内置模块发布才需要开发人员阅读
[HOW_TO_ADD_MODULE.md](./HOW_TO_ADD_MODULE.md)。
